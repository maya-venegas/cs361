How to add a Task

  1. Navigate to the Home page by clicking on the link above.
  2. Add a task title in the text box.
  3. Click the "Add Task" button to create a new task.
  4. Once you have created a task you can click the checkbox on the left to mark an item as completed.
  5. Per task you should spend at least one full timer of 25 minutes working on the task.
